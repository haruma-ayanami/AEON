# Холст дизайна AEON

Снимок холста Claude Design [AEON — дизайн-система и экраны](https://claude.ai/artifact/Sd2HykMpVkjL8XgFnnEe48), версия 157 от 29.10.2026. Иерархия папок та же, что на холсте.

```
design/canvas/
└── project/
    ├── canvas.json        оглавление: страницы, положение и размеры артбордов, заголовки рядов
    ├── aeon.css           токены «Шифр» (th-dark / th-light) и общие классы экранов
    ├── Web*, Win*, Ios*,  общие компоненты: навигация, шапки, таб-бары
    │   And*, Admin*
    ├── found-*, comp-*,   доски дизайн-системы: основы, базовые и доменные компоненты
    │   dom-*
    ├── web-*, ios-*,      экраны-оригиналы по платформам
    │   win-*, and-*
    ├── admin-*, wadm-*,   админ-панель: веб, Windows, iOS
    │   iadm-*
    ├── st-*, lt-*, en-*,  кадры-окна в оригиналы: состояния, светлая тема, EN, адаптив
    │   rs-*
    ├── pr-*               17 интерактивных сценариев
    └── refs-*, Main       референсы и обложка
```

Каждый `*.dc.html` — один артборд. Подключённые экраны (`<dc-import name="…">`) ищутся в той же папке. Кадры `st-*`, `lt-*`, `en-*` и `rs-*` только показывают оригинал с нужными свойствами, поэтому правки вносятся в оригиналы.

Чтобы открыть файлы вне холста, нужен рантайм холста: файл `support.js` рядом с артбордами. Он не входит в снимок, потому что принадлежит типу артефакта. Актуальная версия всегда на холсте, папка — архивная копия.
