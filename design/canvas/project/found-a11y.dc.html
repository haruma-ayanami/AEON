Читается, нажимается, озвучивается

Контраст по WCAG AA в обеих темах, зоны касания по нормам iOS и Android, видимый фокус, подписи для экранного диктора и два языка интерфейса — требования, по которым проверены все экраны макета.

Норма — 4,5 : 1 для текста и 3 : 1 для крупного текста и графики. Пары посчитаны по токенам aeon.css; проверка по всем 135 экранам в обеих темах — без нарушений. Отключённые кнопки (прозрачность 40%) из нормы исключены и всегда подписаны причиной.
