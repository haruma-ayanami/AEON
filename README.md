# AEON

Платформа, объединяющая финтех, крипто-кошельки и P2P-торговлю с эскроу.

- **Кошельки и блокчейны:** EVM-сети, Bitcoin, Solana — депозиты, выводы, подтверждения транзакций.
- **P2P-сделки:** ордера, эскроу, чат в реальном времени, арбитраж споров.
- **Аналитика:** оценка рисков транзакций и анализ портфеля.
- **Клиенты:** веб (Vue 3) и нативное iOS-приложение (SwiftUI).

Стек: .NET, PostgreSQL, Redis, RabbitMQ, Python (FastAPI), Vue 3, Swift.

Подробная архитектура, рекомендации и roadmap — в [ABOUT.md](ABOUT.md).
